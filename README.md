# 手工织锦纹样排版台

直接打开 `index.html` 使用（单文件，无依赖；数据保存在浏览器 localStorage）。

## 功能

- **逐格绘制**：绘制工具下单击或按住拖动连续填色，支持单点/十字/小菱形纹样块，0 号底布色用于擦除。
- **色线统计 / 重复预览 / 断线风险**：任何操作后同步刷新用色格数、锁定格数、剪贴板单元平铺预览与高密度换色行预警。
- **矩形选区**：框选工具在空白处拖出选区；在选区内按住拖动可移动纹样，按住 **Alt/Option** 拖动为复制。
- **剪贴板**：复制 / 剪切 / 粘贴一次；拖动落位时有虚线预览，越界与冲突格红色标出，松手即取消且画布不变。
- **变换**：对选中纹样整体做水平翻转、垂直翻转、顺时针旋转 90°（非方形选区旋转后宽高互换，以选区左上角为锚点重新检查边界）。
- **按行列铺版**：指定目标行列与铺版列数、行数，把剪贴板单元整块铺满。
- **锁定格**：锁格工具单击切换。锁定格不能被绘制、剪切、移动、翻转旋转、覆盖或随铺版改变（复制来源不受限）。
- **冲突处理**：空选区、空剪贴板、越界、撞到锁定格、覆盖已有纹样都会在顶部明确提示并整体取消，绝不静默截断；勾选“允许覆盖”可覆盖普通格，锁定格仍然拒绝。
- **撤销/重做**：每次绘制笔画、粘贴、铺版、移动、翻转、旋转、锁定切换各为一个整体步骤。
- **保存还原**：保存后重开恢复画布与锁定状态；旧版存档（仅 `{cols,rows,cells}`）打开时纹样逐格不变、默认全部未锁定。

## 自检

`node test-logic.js`：用 DOM 桩加载真实脚本，覆盖单格、非方形选区、旋转宽高变化、四次旋转还原、越界/锁定/覆盖冲突原子性、拖放、铺版、撤销重做、新旧存档往返等 32 项断言。
